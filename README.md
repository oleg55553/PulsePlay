# Установка PulsePlay на Windows

## Изменения в 0.8.20

- Исправлен экран выбора способа подключения в мастере хоста: варианты Radmin VPN
  и прямого подключения отображаются на тёмной теме и пояснены отдельно.
- Приглашение теперь видно в отдельном поле, чтобы его можно было скопировать
  вручную сочетанием Ctrl+A и Ctrl+C, если буфер обмена недоступен.
- Добавлена резервная попытка копирования через буфер Tk, если Windows временно
  блокирует основной способ.
- Кнопка «Подключить и играть» проверяет сопряжение и запускает Moonlight сама.
  При первом подключении после подтверждения PIN хостом трансляция стартует автоматически.
- Во время ожидания первого подтверждения и подключения показывается режим ожидания
  с кнопкой «Отключиться» прямо в PulsePlay.

## Изменения в 0.8.19

- Мастер хоста в первую очередь предлагает Radmin VPN, находит его IP и создаёт

- В мастере показано, что выбор приложения запускает его, но не изолирует окно:

- Кнопка настроек открывает локальную панель Sunshine, где хост настраивает

## Изменения в 0.8.14

- Во время трансляции можно отключить звук кнопкой «Выключить звук» и вернуть
  его кнопкой «Включить звук». При возврате восстановится прежняя громкость.

## Изменения в 0.8.13

- Окно вставки приглашения больше не блокирует главное окно: можно одновременно
  пользоваться настройками подключения. Окно приглашения остаётся поверх PulsePlay.

1. Открой [последний выпуск](https://github.com/oleg55553/PulsePlay/releases/tag/latest)
   и скачай `PulsePlay-Setup.exe`.
2. Запусти установщик и следуй шагам мастера.
3. При первом запуске выбери роль: **Хост** — компьютер с игрой; **Гость** —
   компьютер, с которого играют.
4. Мастер сам проверит, установлены ли Sunshine и Moonlight на этом компьютере.
   Если нужной программы нет, нажми кнопку установки — искать сайт и установщик
   вручную не нужно.
   Установка идёт через Windows Package Manager (Winget); Winget показывает
   соглашения и запрос Windows на подтверждение, когда он нужен. Та же кнопка
   позволяет принудительно переустановить выбранную среду, если она повреждена.
5. На хосте создай учётную запись Sunshine и добавь `Desktop` или игру.
   Гость нажимает «Подключиться по приглашению хоста»: PulsePlay сама заполняет
   адрес и игру из приглашения и находит Moonlight. При первом соединении хост
   вводит показанный гостю PIN в Sunshine → PIN. Код и таймер отображаются
   на главном экране PulsePlay до 20 минут; запрос обновляется автоматически.

Установщик PulsePlay автономный: для него не нужен Python. Sunshine и Moonlight
остаются отдельными программами; мастер запускает их установку через Winget
и может принудительно переустановить выбранную программу. Это не удаляет автоматически
настройки Sunshine: если проблема сохраняется, сначала проверь их в панели Sunshine.
Если Winget не установлен, мастер откроет его страницу в Microsoft Store.

Обновление PulsePlay использует тот же AppId и каталог установки
`%LOCALAPPDATA%\Programs\PulsePlay`, поэтому установленная Inno Setup версия
обновляется в существующем месте с одной записью удаления. Папки старых
портативных ZIP-копий в произвольных местах автоматически найти нельзя.

## Сопряжение и диагностика

PIN из окна Moonlight вводится на игровом ПК в панели Sunshine → PIN:
открой `https://localhost:47990` именно на игровом ПК. Не вводи этот PIN в PulsePlay.
Если игровой ПК в другом городе, панель открывай локально на нём, а не на компьютере гостя.

Для диагностики сети открой вкладку «03 Интернет». Сначала на вкладке
«01 Подключиться» введи IP/имя игрового ПК в поле «Адрес игрового ПК», затем вернись
в «03 Интернет» и нажми «Проверить указанный игровой ПК». Результат появится в
журнале PulsePlay; проверка TCP не подтверждает работу UDP, звук или видеопоток.

Сборка рассчитана на Windows x64. Установщик пока не подписан сертификатом
издателя, поэтому Windows может показать предупреждение SmartScreen.

Исправление 0.8.10: кнопка приглашения и подсказка больше не накладываются друг на друга;

Исправление 0.8.11: версия PulsePlay теперь отображается в окне и не остаётся
зашитой на уровне 0.8 после обновления.
Исправление 0.8.12: подключение по приглашению открывает отдельное окно с полем
для вставки, инструкцией и автозаполнением из буфера обмена.

Русскоязычная настольная оболочка для удалённых игр через отдельно установленные
Sunshine и Moonlight Qt. Это исходный код запускаемого приложения, а не готовый
аналог всего Parsec. Видеопоток, звук, клавиатура, мышь и геймпады обслуживаются
Sunshine/Moonlight. PulsePlay не проксирует поток и не добавляет обработку кадров.

## Запуск на Windows

1. Установи Python 3 с компонентом Tcl/Tk и Python Launcher.
2. На игровом ПК установи Sunshine из https://github.com/LizardByte/Sunshine/releases.
3. На принимающем ПК установи Moonlight Qt: https://moonlight-stream.org/.
4. Распакуй весь архив и запусти `Start.bat`. Укажи путь к `Moonlight.exe`, если он
   не найден автоматически. Запускай обычным пользователем, администратор не нужен.
5. На игровом ПК открой https://localhost:47990, создай учётную запись Sunshine.
   Его локальная панель использует самоподписанный сертификат. Добавь игру или
   приложение Desktop. Имя в PulsePlay должно точно совпадать с именем в Sunshine.
6. На принимающем ПК введи IP игрового ПК. Для первого теста оба устройства должны
   быть в одной домашней сети. Нажми «Сопряжение» и введи показанный PIN в Sunshine → PIN.
7. После успешного сопряжения нажми «Играть». Moonlight откроется отдельным окном.
   Если другой Moonlight уже открыт, закрой его перед первым тестом PulsePlay.

Steam Deck, macOS и телефоны могут подключаться к тому же Sunshine штатными
клиентами Moonlight. Собственная оболочка PulsePlay на этих платформах пока не проверена.

## Сборка Windows-установщика

GitHub Actions собирает `PulsePlay-Setup.exe` и `PulsePlay.exe` после изменения
ветки `main`. Файлы доступны в артефактах запуска Actions и в последнем выпуске.
Локально на Windows запусти `Build-Windows.bat`; при наличии Winget он может
предложить автоматически установить Python 3.12 и Inno Setup 6. Нужен интернет.

## Задержка

Стартовый профиль: 1080p, 60 FPS, 20 Мбит/с, auto codec, аппаратный декодер.
Это начальная настройка для теста, а не обещание минимального времени отклика.
Для экрана 120 Гц и стабильной сети попробуй 1080p/120/35 Мбит/с.
Более высокий FPS не всегда снижает общую задержку: возможна перегрузка ПК/сети.

Режим приоритета задержки выключает V-Sync и frame pacing. Возможны разрывы и
неравномерность картинки; сними галочку для более плавной подачи кадров.
Аппаратный декодер принудительный: если устройство/кодек не поддерживаются,
поменяй кодек на H.264. Автоматического перехода на медленное программное
декодирование в этой версии нет. AV1 не гарантированно быстрее H.264/HEVC.

Используй Ethernet на игровом ПК. Сравни показатели встроенной статистики
Moonlight: сеть, декодирование, потеря кадров. Сетевой RTT не равен полной
задержке от нажатия до изображения. Полную задержку измеряют отдельно, например
высокоскоростной съёмкой реакции экрана. Никаких измеренных миллисекунд пока нет.

## Доступ и совместная игра

PIN подтверждает первое сопряжение, после которого клиент остаётся доверенным.
Подтверждения каждой сессии и одноразовых приглашений в PulsePlay пока нет.
Клиент может получить доступ ко всему рабочему столу, не только к одной игре.
Подключай только доверенные устройства. Пароли и токены Sunshine оболочка не хранит;
сохраняются только путь Moonlight, адрес ПК и имя игры в LocalAppData/PulsePlay.

«Отключиться» завершает только запущенный из оболочки локальный процесс Moonlight.
Это не кнопка отключения гостя на хосте. Для прекращения всех сеансов останови
Sunshine на игровом ПК; для отзыва доступа удали сопряжённый клиент в Sunshine.
Закрытие PulsePlay на игровом ПК не отключает Sunshine. Игра после выхода клиента
должна продолжать работать: параметр quit-after отключён.

Совместная игра требует игры с локальным кооперативом и настроенного виртуального
геймпада в Sunshine. Передаётся опция нескольких контроллеров, но распределение
игроков и одновременное подключение нескольких клиентов здесь не тестировались.
Драйверы ввода выбираются и устанавливаются отдельно по документации Sunshine.

## Интернет

### Для хоста и гостя

1. Хост запускает Sunshine и PulsePlay на игровом ПК. В PulsePlay открывает
   «Мой компьютер», проверяет публичный IP и нажимает «Скопировать приглашение».
2. Хост передаёт приглашение гостю любым удобным способом. Оно содержит только
   адрес и название приложения Sunshine; само по себе доступа не даёт.
3. Гость запускает PulsePlay и нажимает «Подключиться по приглашению хоста».
   Программа заполняет адрес и игру из текста приглашения, сама находит
   Moonlight или открывает мастер его установки.
4. При первом соединении гость нажимает «Сопряжение · PIN» и отправляет
   показанный код хосту. Хост вводит его в своей панели Sunshine → PIN.
   После сопряжения гость нажимает «Играть».

Текущий режим передачи — **весь дисплей хоста**. Название игры в Sunshine
указывает, что запустить, но не скрывает другие окна или рабочий стол.
Режим «только выбранное окно» в интерфейсе помечен как недоступный, потому что
для строгой изоляции нужен другой механизм захвата. Не используй текущий режим,
если гость не должен видеть остальной экран.

Для соединения вне дома включи UPnP в Sunshine → Network и на роутере игрового ПК.
Sunshine попробует открыть порты автоматически. PulsePlay только запрашивает
публичный IPv4 у роутера через локальный UPnP; он не меняет настройки роутера,
не использует сервер определения IP, VPN или ретранслятор. Скопируй адрес из
карточки «Мой компьютер / IP» и введи его в PulsePlay на втором ПК, находящемся
в другой сети. Сначала нажми «Проверить указанный игровой ПК», затем выполни
PIN-сопряжение и запусти игру. Первое сопряжение удобнее сделать в домашней сети.

Если автоматическая настройка не сработала, закрепи локальный IP игрового ПК
в DHCP роутера и направь на него TCP 47984, 47989, 48010 и UDP 47998, 47999,
48000, 48002, 48010. Узнай WAN IP в панели роутера, если локальный UPnP
недоступен. При CGNAT или двойном NAT нужен публичный IPv4 от провайдера.
Без доступного публичного адреса прямой способ не работает. Динамический
публичный IP может измениться; тогда нужно передать новый адрес.

### Если провайдер — Ростелеком

В разделе «Интернет» нажми «Скопировать запрос в Ростелеком» и передай текст
оператору через официальный личный кабинет или по телефону. Спроси именно о
**публичном IPv4 без CGNAT** и входящих соединениях. У Ростелекома встречается
опция «Фиксированный IP», но её наличие, цена и техническая возможность зависят
от адреса и договора. Само название услуги не гарантирует, что игровой ПК станет
доступен извне: после ответа проверь WAN-адрес роутера и соединение из другой
сети. Если провайдер не может предоставить публичный IPv4, текущий прямой режим
PulsePlay через Sunshine работать не будет.

### Вариант с Radmin VPN

Если допустим сторонний сервис, Radmin VPN может соединить два Windows-ПК
из разных городов в виртуальную сеть, в том числе когда у хоста CGNAT.
Установи Radmin VPN на оба ПК, создай сеть на ПК хоста, а на гостевом ПК
вступи в неё по имени и паролю. В PulsePlay на хосте открой «Мой компьютер»,
выбери «Через Radmin VPN», впиши адрес этого ПК из Radmin VPN и скопируй
приглашение. Гость вставляет приглашение в PulsePlay и выполняет обычное
PIN-сопряжение Moonlight/Sunshine. Программа Radmin VPN должна быть запущена
на обоих ПК во время игры.

Звук игры передаётся Sunshine/Moonlight вместе с изображением и при прямом
подключении, и через Radmin VPN. Если видео есть, а звука нет, на хосте проверь
Sunshine → Audio/Video → Stream Audio (включено) и работающий аудиовыход.
Sunshine по умолчанию захватывает системное устройство вывода; при нескольких
устройствах укажи нужный Audio Sink. На гостевом ПК проверь громкость Moonlight
и выбранное в Windows устройство вывода звука. В PulsePlay добавлен ползунок
«Громкость у гостя»: он сразу меняет уровень только приложения Moonlight в
микшере Windows и не меняет общую громкость компьютера или звук на хосте.
Для этого варианта не нужен публичный IPv4 и обычно не нужен проброс портов.
Проверь соединение из другой сети: Radmin VPN может использовать relay/TCP,
что способно увеличить задержку. Это сторонняя служба Famatech, поэтому
вариант не удовлетворяет требованию «без стороннего сервиса».

Проверка PulsePlay открывает TCP-соединения, но не проверяет UDP, видео или
управление. Запускай её из другой сети; многие роутеры не поддерживают NAT
loopback. Не открывай в интернет административную панель Sunshine (TCP 47990).
После использования удаляй ненужные сопряжённые клиенты. Если внешний доступ
больше не нужен, отключи UPnP в Sunshine или убери ручные правила роутера.

## Что проверено и что осталось

Автоматические проверки: валидация адресов/настроек, единицы битрейта,
формирование отдельных аргументов команд, переключение параметров задержки,
чтение повреждённых настроек и сохранение. Запуск без shell=True.
Параметры сверены с исходниками CLI Moonlight Qt на 26.10.2026:
https://github.com/moonlight-stream/moonlight-qt/blob/master/app/cli/commandlineparser.cpp
Изменения новых/старых версий Moonlight могут потребовать адаптации.

Автоматическую сборку Windows и тесты проверяет GitHub Actions. Реальное
сопряжение, видео, звук, контроллеры и интернет зависят от компьютеров и сети;
для проверки выполни CHECKLIST.md на двух устройствах.

## Разработка

`python -m unittest -v` — тесты. `python app.py` — запуск интерфейса.
Стандартная библиотека Python; внешних Python-зависимостей для запуска нет.
Sunshine и Moonlight не включены в архив и остаются отдельными проектами.

## История 0.2: первый интернет-тест

Ниже описано прежнее подключение через Tailscale; в версии 0.7 оно заменено
прямым подключением, описанным выше.

Добавлены вкладки Интернет и Права хоста. Интернет работает через отдельно
установленный Tailscale, а не собственный сервис PulsePlay. Установи Tailscale
на оба устройства: https://tailscale.com/download/windows. Для своих устройств
используй один аккаунт, для друга — Share конкретного игрового ПК в панели
https://login.tailscale.com/admin/machines. Это сетевой доступ к устройству
согласно политике Tailscale, не изоляция только игры. Не передавай свой аккаунт.

На принимающем ПК в поле адреса укажи Tailscale IP игрового ПК, показанный
в его Tailscale. Затем Интернет → Проверить указанный игровой ПК. Проверяются
состояние Tailscale, результат tailscale ping и доступность стандартного TCP 47989.
Для собственного изменённого порта диагностика не подходит. Для проверки именно
интернета устройства должны находиться в разных сетях.

Прямой маршрут предпочтителен; DERP/relay не считать успешным тестом низкой
задержки. TCP-проверка не проверяет UDP, поток, права, кодек или задержку ввода.
После диагностики выполняются PIN-сопряжение и запуск игры как в разделе выше.

Вкладка Права хоста создаёт текст настроек для ручного внесения в Sunshine.
Она НЕ применяет их автоматически и НЕ меняет права каждого гостя отдельно.
Все флаги по умолчанию выключены; отдельно отключается native_pen_touch.
На хосте закрой текущие сеансы, внеси значения в Configuration → Input, сохрани

пока тест не пройден. Ограничение захвата/ввода одной игрой не реализовано.

## Новое в 0.3: мой IP

В верхней части окна автоматически показывается Tailscale IP этого компьютера.
На игровом ПК нажми «Скопировать IP» и отправь адрес другу вручную. Друг вводит
его в поле «Адрес игрового ПК» у себя. Кнопка «Обновить» повторяет чтение после
входа в Tailscale или смены сети. При ошибке старый IP очищается и копирование
блокируется. Предпочитается IPv4; при его отсутствии отображается IPv6 Tailscale.
Обычный локальный, публичный IP и адреса других устройств не подставляются.
Сам IP не выдаёт доступ: другу нужны Share устройства в Tailscale и сопряжение
Sunshine. Отправка сообщения из PulsePlay не выполняется.

Проверено 18 автоматических тестов. Новая Windows GUI-функция на реальном ПК
ещё не проверена; ограничения и статус проверки потока из раздела 0.2 сохраняются.

## Новое в 0.4: удобство и полный экран

На вкладке подключения: IP с кнопкой вставки, имя игры, профиль качества,
«Открывать игру на весь экран», кнопки первого сопряжения и запуска.
Путь Moonlight, кодек, FPS, битрейт и статистика убраны в дополнительные
настройки. Если Moonlight не обнаружен, настройки сразу раскрыты.
Сохраняются все параметры при запуске и закрытии; статистика по умолчанию
выключена, чтобы не закрывать игру. Окно имеет вертикальную полосу прокрутки.

Полноэкранный режим включён по умолчанию: Moonlight получает
--display-mode fullscreen. При снятии галочки запускается windowed.
Видеопоток отображается отдельным окном Moonlight, не внутри PulsePlay.
У оболочки нет достоверного события «соединение установлено»; она не выдаёт
запуск процесса за успешное подключение и не сворачивается по таймеру.

Во время игры: Ctrl+Alt+Shift+X переключает полный экран/окно,
Ctrl+Alt+Shift+Q завершает поток, оставляя игру на игровом ПК.
Источник: https://github.com/moonlight-stream/moonlight-docs/wiki/Setup-Guide

19 автоматических тестов прошли, включая команды обоих режимов экрана.
Визуальная проверка Windows, реальные подключение и переключение экрана
здесь ещё не выполнены. Проверить на Windows: запуск fullscreen, переключение
в окно, выход сочетанием клавиш, сохранение параметров, вставку IP,
раскрытие настроек и доступность элементов при масштабировании 150%.

## Новое в 0.5: оформление

Графитовая тема с мягким зелёным акцентом, боковая навигация вместо вкладок,
заголовки разделов, отдельная карточка своего IP, увеличенный адрес, основная
кнопка «Играть». Журнал по умолчанию скрыт, показывается по кнопке и автоматически
при выдаче PIN, результатах диагностики и ошибке процесса. Подготовленный профиль
прав тоже открывает журнал. Настройки и интернет-функции сохранены.

Минимальный размер окна 1080×650; содержимое прокручивается вертикальной полосой.
Это нативный Tkinter-интерфейс без дополнительных Python-зависимостей.
Проверена компиляция и 19 тестов логики. В этой среде отсутствует графический
сервер, поэтому визуальная проверка нового интерфейса и проверка на Windows
не выполнены. Перед выпуском проверить все четыре раздела, фокус клавиатуры,
раскрытие журнала и настроек, масштабирование 100/150/200%.

## Новое в 0.6: контекстные подсказки

Значки «?» возле IP, имени игры, Moonlight, профиля качества, разрешения, FPS,
битрейта, кодека, полного экрана, задержки, статистики, сопряжения, интернета
и прав ввода. Наведи мышь примерно на треть секунды или нажми на значок.
Также можно перейти к значку клавишей Tab; подсказка откроется при фокусе.
Enter/Пробел открывают повторно, Escape закрывает. При уходе мыши/фокуса
подсказка исчезает. Подсказки не меняют настройки и не требуют интернета.

Проверены компиляция и прежние 19 тестов. Визуальное поведение подсказок
на Windows пока не проверено.
